# CPP Memory
This is a little memory game in C++ using the FTXUI library.

# Rules
Select two cells to show their value.
If the two cells have the same value, they will remain face-up; otherwise, they flip back to being face-down.
The goal is to find all the pairs.

# Controls
Use z,q,s and d to move the cursor and space to select a cell.
Use x to quit the game.
